04 / Flechas y conectores

Vocabulario de flechas.

Todas las flechas son SVG con un único marker reutilizable. Ocho variantes cubren el 95% de los casos — de la recta simple al flujo multi-nodo animado.

Snippets básicos

IDSVGCuándo
AR-01 <line ... marker-end="url(#ah-ink)"/> Flujo lineal simple A → B.
AR-03 <path d="M x y L x y L x y L x y" ... /> Cuando los elementos no están alineados.
AR-04 <path d="M x y C cx cy, cx cy, x y" ... /> Conectores orgánicos entre nodos distantes.
AR-06 stroke="#F5C518" + marker-end="url(#ah-y)" La flecha que lleva el concepto clave.
AR-07 stroke-dasharray="6 4" + #E11D2E Error, drop, conexión rota.
AR-08 stroke-dasharray: 4 6; animation: dashMove 1.6s linear infinite; Cuando hay que sugerir movimiento continuo.
