01 / Colores

Paleta mínima, acentos escasos.

Cuatro colores core. El blanco es el lienzo, el negro es la estructura, el amarillo es la señal, y el rojo sólo aparece cuando algo es verdaderamente crítico. Todo lo demás es una variación tonal del gris.

Core

White #FFFFFF Lienzo base
Ink #0A0A0A Texto · estructura
Yellow #F5C518 Acento · señal
Red #E11D2E Crítico · ≤ 3%
Green #0D8A4E Positivo · completado
Muted #8A8A8A Etiquetas · meta

Uso del amarillo y el rojo

El amarillo resalta una idea, un paso clave, una palabra. El rojo detiene la lectura — sólo para errores, alertas reales o el "no hacer".
