Movimiento con intención.

Doce micro-animaciones con sus curvas y duraciones. El movimiento es una herramienta didáctica: dirige la mirada, separa pasos y sugiere flujo — no decora.

Reglas

  • Duración base 380 ms para casi todo. Sólo usa 620/900 ms cuando sea narrativo.
  • Las salidas (exit) suelen ser 40–60% más rápidas que las entradas.
  • No animes más de 3 elementos en paralelo; usa stagger (delay 80–120 ms).
  • El amarillo se anima al entrar; no lo dejes pulsando permanentemente.
  • Respeta prefers-reduced-motion: desactiva translate/scale, conserva opacity.

Snippet base

/* Entrada estándar */ @keyframes enterUp { from { opacity: 0; transform: translateY(16px); } to { opacity: 1; transform: translateY(0); } } .enter { animation: enterUp 380ms cubic-bezier(.2, .7, .2, 1) both; } /* Respeta reduced-motion */ @media (prefers-reduced-motion: reduce) { * { animation: none !important; transition: none !important; } }
