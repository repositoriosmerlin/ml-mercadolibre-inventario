Cuándo usar cada estilo

AR-LAB-01 · ELBOW

Elbow / Flow

Lo más legible para jerarquías y pipelines en grid. Las curvas de 90° nunca se cruzan en diagonal.

pipelinelayout
AR-LAB-02 · CURVE

Curve / Gesture

Vector dibujado a mano — comunica intención y narrativa. Perfecto para historias y explicaciones.

storyonboarding
AR-LAB-03 · RAIL

Data rail

Riel fijo + pulsos en movimiento. Usa cuando quieras sugerir flujo continuo de datos o eventos.

streaminglive
AR-LAB-04 · CALLOUT

Line / Callout

Punteada y fina — señala referencias, anotaciones, relaciones débiles. Baja jerarquía.

/* Elbow con flujo animado */ .ln.flow-anim { stroke: #F5C518; stroke-width: 2; stroke-dasharray: 4 8; animation: flowDash 1.8s linear infinite; } @keyframes flowDash { to { stroke-dashoffset: -24; } } /* Curve gestural */ .gesture { fill: none; stroke: #F5C518; stroke-width: 3.5; stroke-linecap: round; } /* Rail — pulso que viaja sobre el path */ <path id="rail" class="ln y-soft" d="..." /> <circle r="5" fill="#F5C518"> <animateMotion dur="2.2s" repeatCount="indefinite"> <mpath href="#rail"/> </animateMotion> </circle> /* Callout */ .ln.dash { stroke-dasharray: 10 6; }
